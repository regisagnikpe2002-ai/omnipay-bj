Double authentification OMNIPAY

Ce secret est créé dans votre téléphone et n'est envoyé nulle part. Il protège l'administration (tableau de bord, ledger, retraits, remboursements).

1. Votre secret

…
Ouvrir mon application d'authentification

Dans Google Authenticator, Authy ou Microsoft Authenticator : « Ajouter un compte » → « Saisir une clé de configuration » → nom « OMNIPAY », collez ce secret, type « basé sur le temps ».

2. Vérifier que ça fonctionne

Tapez le code à 6 chiffres affiché par l'application.

3. L'activer dans Render

Render → votre service → Environment → ajoutez ADMIN_TOTP_SECRET avec ce secret, puis redéployez. Ensuite, la page d'administration demandera la clé ET le code à 6 chiffres. Notez le secret dans un endroit sûr hors ligne : sans lui (ou sans votre téléphone), vous devrez retirer la variable dans Render pour retrouver l'accès.
